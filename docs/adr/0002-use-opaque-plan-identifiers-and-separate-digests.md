# Use Opaque Plan Identifiers And Separate Digests

InfraGate will use an opaque **Plan Identifier** as the stable workflow handle for MCP calls, approval URLs, audit correlation, and storage, while using separate **Intent Digest** and **Review Digest** values for integrity. The **Intent Digest** proves the executable mutation intent is unchanged, and the **Review Digest** proves the approved review snapshot is unchanged, including envelope metadata, evidence artifact digests or digest-bound references, redaction metadata, and review-surface context; the plan identifier itself must not become an integrity mechanism because deterministic identifiers can leak same-operation equality and create awkward collision or idempotency semantics.
