[safety] Don't remove intentional redundant safety guards just to reduce complexity - keep them with an explanatory comment and test. (cause: defense in depth)
[mcp-debug] Don't trust `IsError = False` in gateway logs when every tool returns `An error occurred invoking '<toolName>'` — that text is the MCP SDK's generic catch-all for downstream DI/construction failures; run the downstream binary standalone or inspect its stderr to see the real exception. (cause: silent SDK error wrapping)
[containers] Don't ship host-mounted secrets at mode 0600 to chiseled .NET images — the container's `$APP_UID` (e.g. 1654) doesn't match the host UID and reads fail silently inside DI factories; grant ACL `user:<container-uid>:r` with `setfacl` (preserves owner-only perms) or fall back to chmod 0644 for ephemeral dev tokens. (cause: UID mismatch across bind mounts)
[bash-scripts] Don't reference variables under `set -u` that aren't defined locally — `create-demo-kubeconfig.sh` was referencing `GATEWAY_APP_UID` defined only in `setup-development-deploy.sh`, so `prepare_compose_persistence_dirs` aborted before chowning the bind-mount dirs. Define shared constants in every script that uses them. (cause: shared constants implicitly duplicated, not imported)
[keycloak-import] Don't rely on `--import-realm` to merge built-in client scopes — if `clientScopes` is present in the JSON, only those scopes are created; define `profile`, `email`, `roles`, `web-origins`, `acr`, `basic` explicitly when overriding. (cause: import replaces, doesn't merge)
[keycloak-import] Don't put custom scope names in `defaultDefaultClientScopes` — they're validated before the `clientScopes` section is processed and crash startup; keep custom scopes in `defaultOptionalClientScopes` and reference them per-client. (cause: import-time validation order)
[keycloak-import] Don't leave the trusted-hosts policy with both `host-sending-registration-request-must-match` and `client-uris-must-match` set to `false` — Keycloak refuses to start; keep `client-uris-must-match: ["true"]` to restrict DCR redirect URIs. (cause: policy-required validation invariant)
[keycloak-import] Don't request `offline_access` without first defining the `offline_access` realm role and assigning it (directly or via a default composite) to the users — Keycloak rejects the code-to-token exchange with `Offline tokens not allowed for the user or client`. (cause: missing realm-role dependency)
[silent-failures] Don't await audit/side-effect writes inside an if-branch that must return a user-readable message — if the audit write throws (e.g. approval-store directory not writable) the exception replaces the meaningful refusal message and the MCP SDK swallows it as the generic "An error occurred invoking" string. Wrap audit writes in their own try/catch so the refusal is always returned. (cause: approval store permission failure masking dry-run error)
[silent-failures] Don't leave `approvalStore.CreatePlanAsync` and similar store writes uncaught at the top of a tool call — unhandled IO/permission exceptions propagate to the MCP SDK which returns a generic error instead of a useful message. Add try/catch with a formatted return string and log the exception before it disappears. (cause: missing error boundary around file write)
[mcp-observability] When adding ILogger to a class with multiple test-facing constructors, prefer injecting NullLogger<T>.Instance in tests rather than adding "convenience" overloads to production code — keeps production constructors honest and avoids silent no-logging paths in prod. (cause: test usability vs production clarity)
